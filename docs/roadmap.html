충전기 사업, 지금 어디까지 왔나

지금까지 대화에서 나온 걸 한 장으로 정리했다. 지금 만든 건 전부 "데모"이고, 실제로 여러 업체를 받는 서비스는 이후 단계에서 다시 설계한다.

전체 로드맵

4단계로 간다. 지금은 1단계, 데모를 만들어서 보여주는 단계다.

01
데모
충전기 상태가 바뀌면 화면에 바로 반영되는 걸 보여주는 시연용 사이트 하나 완성.
지금 여기
▸
02
파일럿(B2B)
지인·공공기관에 데모 보여주고 반응 확인. 실제 중소업체 1~2곳에 저렴하게 OCPP 연동 대행.
▸
03
데이터 자산화
연동된 업체 수가 늘면서, 큰 지도 앱엔 없는 중소 충전기 실시간 상태 데이터가 쌓임.
▸
04
확장
쌓인 데이터로 자체 소비자 앱을 내거나, 네이버맵 등에 데이터를 공급(B2B2B).

잊지 말아야 할 것

  • 공공기관 영업은 순서가 있다. 나라장터 등록 → (가능하면) 혁신제품/벤처 인증 → 소규모 실증사업으로 레퍼런스 확보 → 본 계약. 예산 주기 때문에 최소 6개월~1년 리드타임.
  • 지인은 정보원이지 결정권자가 아니다. 담당 부서·예산 시기 파악, 담당자 소개 정도로 활용. 식사·선물 등은 청탁금지법 문제가 될 수 있음.
  • OCPP 미지원 구형 장비. 펌웨어 업데이트로 해결 → 안 되면 릴레이/Modbus 신호를 게이트웨이로 중계 → 그래도 안 되면 업체 동의하에 물리 센서 부착(유료 애드온).
  • 충전기는 위치 데이터가 있어야 한다. 한 업체도 충전소가 여러 곳에 흩어져 있어서, CP-1 같은 코드만으론 어디 있는 건지 알 수 없음. 위도/경도를 붙여 지도에 핀으로 표시(상태별 색상)하고, 충전기 수가 많아지면 목록/표 뷰를 보조로 추가.
이 페이지 자체에 대해: 지금 만든 데모는 충전기 3대·업체 구분 없음으로 고정된 시연용이다. 파일럿 단계로 넘어갈 때는 이 코드를 확장하는 게 아니라, company_id 기반의 공유 구조로 다시 설계해야 한다.
대화 중 나온 휴지 재생지 아이디어는 이 로드맵과 무관한 별개의 주제라 여기엔 포함하지 않았다.
